# 通用快捷启动与网页模型配置

日期：2026-10-18。状态：设计与实施计划已确认，实现及模拟回归完成；待发布确认，未提交或推送。

## 目标与方案

让下载项目的 Windows 用户在自行安装 Docker Desktop 后启动工作台，并在网页填写自己的模型配置，不依赖开发者盘符或密钥。首版优先兼容 DeepSeek Chat Completions。

采用“网页本机配置为主、现有环境配置回退”。仅用 `.env` 不满足网页设置目标；完整多厂商配置中心超出首版需要，因此不采用。

仅修改项目一，保留已有 README 改版、`.env` 和业务数据卷。不改变检索、引用校验及历史存储语义，不增加多用户或套餐托管。

## 通用启动

- 公开 CMD 入口及 PowerShell 脚本，移除对应 Git 忽略项；个人快捷方式、图标与本机配置仍排除。
- 优先发现 PATH 上的 Docker，再检查标准系统级和用户级安装目录；非标准安装可显式指定路径，不发布个人盘符。
- 不改写 DOCKER_HOST、DOCKER_CONTEXT、DOCKER_CONFIG，不自动安装软件或切换引擎。
- 用户先自行安装、打开 Docker Desktop，使用本机 Linux 容器引擎。脚本检查引擎与 Compose 是否就绪。
- 日常不自动构建、拉取；首次缺镜像时提示构建命令。显式构建选项由用户主动选择，提示会下载依赖并构建镜像。
- 不删除容器或数据卷，不改变 Compose 项目名。启动后核对健康接口、数据库访问和前端页面再打开浏览器；失败保留排查提示。
- 支持不打开浏览器模式与有界超时。无 `.env` 也能进入网页配置，Compose 保留可选 `.env` 兼容，说明所需版本；不覆盖既有文件。

## 配置与生效

- 独立模型配置存储模块，默认 `runtime-config/model.json`；不写业务数据库或前端构建参数。Git 和 Docker 构建排除该目录，Compose 挂载至容器以跨重建保留，原业务数据卷不变。
- 网页保存的完整配置优先；文件不存在时回退 `.env`/环境变量。文件损坏明确报错，不静默切换账号；保存失败保留旧配置。
- 同目录临时文件加原子替换，尽可能收紧权限。这是本机明文文件，不承诺加密保险箱或阻止电脑管理员读取。
- 每次模型请求开始时解析一致快照，下一次请求使用新配置，进行中的请求不切换。

## 接口和界面

- 设置页增加 Base URL、模型名和密码型 API Key 输入，保留来源数量设置。
- `/api/model-config` 提供 GET 状态、PUT 保存；`/api/model-config/test` 提供 POST 连接测试。
- 状态和保存响应仅返回配置是否完整、地址、模型名、配置来源，不返回密钥或密钥长度。
- DeepSeek 预填 `https://api.deepseek.com`、模型示例 `deepseek-flash`（2026-10-18 官方文档），允许修改模型名；不自动修改用户原有配置。
- 保存只校验和落盘，不请求模型。测试由用户主动点击，提示可能计费，使用固定简短文本，不发送资料；不自动保存、重试或降级模型。
- 首次配置必须输入密钥；已配置时留空可沿用，但更换 Base URL 必须重新填写，避免旧密钥被发往新地址。
- 保存成功清空密码框；密钥不写 URL、localStorage、sessionStorage 或日志。提交时浏览器仍会短暂持有输入，不宣称密钥从未进入浏览器。
- 未配置显示引导，不阻止文档管理、索引；问答需要完整配置。

## 安全边界

- 单用户本机部署，保留 `127.0.0.1` 端口绑定，不提供公网安全保证。
- 配置接口约束可信本机 Host、同源请求，拒绝跨站修改；不靠前端按钮隐藏保护设置。
- URL 禁止内嵌账号密码、查询串、片段和控制字符；远程要求 HTTPS，回环本地服务可使用 HTTP。
- 上游不跟随重定向；响应及异常不回显密钥、提交 input、上游正文、请求头或内部异常。
- 自定义服务地址属于本机用户的信任选择，不宣传完整 SSRF 防护。
- 用户自备 DeepSeek API 账户、密钥和额度；网页订阅或其他 Coding Plan 不保证能直接用于 API。
