# Release notes (controlled evaluation material)

Version 2.1 was released on 2026-08-20. It adds manual review before a planner creates a final schedule. Version 2.1 also changes the default retrieval source count from three to five.

Version 2.0 was released on 2026-06-01. It introduced streaming status updates and the 90 second production timeout. Neither version changes the 14 day checkpoint retention period.
